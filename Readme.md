# OpenIso8583.Net

OpenIso8583.Net is a .Net message builder and parser for ISO 8583 financial messages

# Use at own risk

## Updates Added
  * .Net 10
  * MasterCard ISO8583 Clearing messages
  * Updated Iso8583Post to be reasonably up-to-date
  * enabled EBCDIC and ASCII support for MasterCard IPM messages
  * ISO8583Disaply tool to enable inspection of a MasterCard IPM files 
	* as CSV, or 'raw' formats
	* convert between from EBCDIC to ASCII and visa versa, taking into account MicrosFocus Cobol formats, and BankServ/PayInc headers & Trailers
